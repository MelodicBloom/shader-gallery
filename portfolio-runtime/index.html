How it works

A camera ray intersects an asymmetric ellipsoid. Object-space bands and three oriented layer responses catch a moving light, while Fresnel color and a polished top reflection reveal depth. This is an artistic optical study, not measured nacre transport.

GLSL ES 3.00 → typed uniforms → Zustand vanilla store → raw WebGL2. The renderer owns frame time; semantic changes enter the store only on interaction. The 3 × 3 capture matrix records inputs, not visual or performance conclusions.
