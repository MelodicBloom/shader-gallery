Reproducibility

Animated timestamps are quantized to 1/30 s for replay. Receipt stores normalized controls, frame time, source identity, and a non-cryptographic geometry fingerprint. Canvas output may vary by browser.

No microphone data, uploads, external scripts, or third-party network calls. A local static server is required for ES modules. Scene complexity is capped at 30,000 line segments per frame.
